# ConveneCore SaaS conversion — foundation
Public blank format library and browser-local format builder. No meeting data is made public. Existing system remains a single-organization deployment until tenant ownership, membership and authorization are migrated and tested.
Next: server-owned templates with versioned schema, tenant isolation for every model and storage object, meeting format snapshots, validated structured AI outputs with transcript evidence, customized export renderer, and draft/review/approval states. Preserve organization settings and existing records. Do not expose patient-identifiable or restricted information in public templates. Do not launch multi-tenant onboarding before cross-tenant access tests pass. Local draft storage must not be used for sensitive meeting contents.

## Integrated structured minutes
Authenticated minute editors can save a format to their account, attach a snapshot in the Minutes tab, generate from the transcript, edit sections, and export PDF/DOCX/TXT in that same order. An administrator can finalize once required sections are recorded. Selected formats are private; public presets remain blank. The existing meeting pipeline retains legacy summaries and task records; structured action tables are not yet synchronized with the task tracker. Multi-tenant organization isolation remains unimplemented. AI evidence checks are not a substitute for human review. Do not deploy until CI and live integration tests pass.
